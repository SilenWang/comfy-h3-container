# 背景：截图 → 干净背景 → 多时段 / 天气变体

用 `qwen_image_edit_reference.json`，机制和角色链路一致：**图 1 锁结构，图 2 给变量，指令只改该改的地方**。

> 角色链路是逐格实测过的；下面的背景写法和它同一套机制，但还没有像角色那样逐步实测——第一次跑请按「先出 1 张、用 `get_image` 看一眼再批量」的节奏。

## 1. 从截图得到干净背景

目标：没有人物、没有姓名条 / 字幕 / 水印、透视和建筑物位置不动的整幅背景。

1. **图 1** = 一张尽量少人物的关键帧（候选帧的筛选走仓库既有流程，本技能只管出图）。
2. **图 2** = 同地点、同画风的另一帧（可选；放一张更干净的更稳）。
3. 有残留人物 / UI 时开 mask：把要重画的地方设成透明（alpha=0），并按下文接线；接线方式见 [character-pipeline.md](character-pipeline.md) 第 1 步（api JSON 里补上 `Grow Mask` / `Set Latent Noise Mask` 两个节点）。
4. 指令（按缺什么写，一次只改一类）：

```text
去掉画面里的人、姓名条、字幕与水印，
补全被挡住的地面、墙面与家具；建筑物位置、透视与光影方向保持不变
```

5. 出图后先 `get_image` `{action:"get", filename}` 看一眼，再按仓库既有的背景验收流程过门槛。

## 2. 同一地点的多时段 / 天气

结构不漂的关键是**每次都带图 1**，且只在指令里改光与天气。

1. **图 1** = 已定稿的干净背景（同一地点全项目复用这一张）。
2. **图 2** = 同地点的另一个时段（如果有），指令写「改成图 2 的样子」；没有就纯靠指令。
3. 指令示例：

```text
把白天改成黄昏，加暖色逆光与长阴影，
建筑物位置、透视、家具与构图保持不变，只改光线与色调
```

```text
加夜雨：地面反光、窗外雨痕、室内暖光更亮，
结构、透视与家具位置保持不变
```

4. 每个时段都从**同一张图 1** 出发，不要拿上一张变体继续改——多改一轮结构就会漂。

## 3. 输出与归档

- 输出落在 ComfyUI 的 `output/qwen_edit/…`（`SaveImage.filename_prefix` 可改），按 `bg_<地点>_<时段>.png` 命名。
- 需要固定尺寸时在外部按目标尺寸缩放；ComfyUI 侧输出尺寸由 `FluxKontextImageScale` 决定（1920×1080 → 1392×752）。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 建筑物 / 家具位置漂了 | 指令没写「结构 / 透视保持不变」，或从变体继续改 | 从原图 1 重跑，指令显式锁结构 |
| 人物去不干净 | mask 太小或没开 mask 分支 | 涂白人物区域并取消 Bypass |
| 画面出现字幕残影 | 图 2 带 UI，或指令没点名去除 | 换干净图 2；指令列出要去的元素 |
